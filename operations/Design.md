# Design System

The design system for **KodasHub** is derived directly from the icon's gradient (vibrant cyan to deep royal blue) and dark wordmark typography to ensure visual continuity across your hosting and technical support platform.

---

## Color Palette

| Category                       | Color Name      | Hex Code  | Usage                                                                      |
| ------------------------------ | --------------- | --------- | -------------------------------------------------------------------------- |
| **Primary Accent**             | Electric Cyan   | `#00B4D8` | Primary buttons, active tab indicators, high-priority highlights.          |
| **Secondary Accent**           | Royal Blue      | `#0052D4` | Primary brand gradient end-state, focused input states, secondary buttons. |
| **Primary Text / Dark Accent** | Deep Navy       | `#0B132B` | Headings, main text content, navigation background (in dark mode).         |
| **Background / Canvas**        | Clean Off-White | `#F8FAFC` | Light mode main canvas background, content container fill.                 |
| **Card / Surface**             | Pure White      | `#FFFFFF` | Dashboard cards, pricing tables, modal dialogs.                            |
| **Muted / Border**             | Slate Gray      | `#E2E8F0` | Structural dividers, inactive form borders, secondary text.                |
| **Alert / Success**            | Emerald Green   | `#10B981` | SSL active badges, server uptime status indicators.                        |
| **Alert / Warning**            | Amber           | `#F59E0B` | Domain expiration warnings, DNS propagation pending states.                |

## Typography

**Primary Font Family:** **Plus Jakarta Sans** or **Inter** (Google Fonts)

- **Characteristics:** Modern, geometric sans-serif with excellent legibility at small sizes, ideal for technical dashboards, status monitors, and hosting panels.

### Type Hierarchy Scale

- **Headings (H1 - H3)**
- **Font:** Plus Jakarta Sans
- **Weight:** SemiBold (600) / Bold (700)
- **Color:** Deep Navy (`#0B132B`)
- **Application:** Page titles, service headers, pricing tier titles.

- **Subheadings (H4 - H6)**
- **Font:** Plus Jakarta Sans
- **Weight:** Medium (500)
- **Color:** Royal Blue (`#0052D4`) or Deep Navy (`#0B132B`)
- **Application:** Section headers, card titles, feature descriptions.

- **Body Text**
- **Font:** Inter / Plus Jakarta Sans
- **Weight:** Regular (400)
- **Color:** Dark Slate (`#1E293B`)
- **Application:** General text, service breakdown lists, knowledge base articles.

- **Code / Technical Data**
- **Font:** **JetBrains Mono** or **Fira Code**
- **Weight:** Regular (400) / Medium (500)
- **Color:** Deep Navy (`#0B132B`) or Cyan (`#00B4D8`)
- **Application:** DNS records (A, CNAME, MX), terminal logs, cPanel file paths, SSL certificates details.
